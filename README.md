# Эмулятор языка оболочки ОС

Учебный проект по дисциплине «Конфигурационное управление»
(ИКБО-41-25, Вариант №22). Практическая работа №1, этапы 1-5.

## 1. Общее описание

Эмулятор командной строки UNIX-подобной ОС с графическим
интерфейсом (GUI). Поддерживает параметры командной строки,
стартовый скрипт и виртуальную файловую систему (VFS) из
CSV-файла. VFS целиком хранится в памяти, все изменения
(`rmdir`, `mv`) происходят только в памяти.

## 2. Описание всех функций и настроек

- Окно с заголовком `Эмулятор - [vfs]`, полем вывода и строкой ввода.
- Парсер разбивает ввод на команду и аргументы по пробелам.
- Параметры командной строки:
  - `--vfs ПУТЬ` - путь к CSV-файлу VFS;
  - `--script ПУТЬ` - путь к стартовому скрипту.
- При запуске в окно выводятся параметры и информация о VFS ([debug]).
- Стартовый скрипт выполняется построчно, ошибочные строки
  пропускаются с номером строки, ввод и вывод видны в окне.
- Формат VFS: CSV со столбцами `path,type,content`; `type` - `dir`
  или `file`, содержимое файлов в base64, вложенность задаётся
  полным путём (`/docs/projects/2024/report.txt`).
- Команды:
  - `ls [путь]` - содержимое папки или указанного пути;
  - `cd [путь]` - сменить папку (`..`, `.`, абсолютные и
    относительные пути; без аргумента - корень);
  - `who` - имя пользователя ОС, терминал и время запуска;
  - `cat файл...` - вывести содержимое файлов;
  - `tail [-n N] файл` - последние N строк (по умолчанию 10);
  - `rmdir папка...` - удалить пустые папки;
  - `mv источник назначение` - переименовать или переместить файл
    или папку (если назначение - папка, источник кладётся внутрь,
    существующий файл заменяется);
  - `vfs-info` - имя VFS и SHA-256 её текущих данных;
  - `vfs-save путь` - сохранить текущее состояние VFS в CSV;
  - `exit` - выход.
- Ошибки (неизвестная команда, неверные аргументы, нет файла или
  папки, папка не пуста, VFS не загружена) выводятся в окно,
  программа продолжает работу.

## 3. Описание команд для сборки проекта и запуска тестов

Зависимости не нужны (только стандартная библиотека Python).

    python3 src/main.py [--vfs ПУТЬ] [--script ПУТЬ]
    python3 -m pytest tests/ -v

Проверка команд этапов 4 и 5:

    python3 src/main.py --vfs vfs/demo.csv --script scripts/startup_stage4.txt
    python3 src/main.py --vfs vfs/ops.csv --script scripts/startup_stage5.txt

Скрипты ОС для разных вариантов VFS: `scripts/test_vfs_*.bat` и
`scripts/test_vfs_*.sh`.

## 4. Примеры использования

    $ ls
    box
    docs
    empty1
    notes.txt
    readme.txt
    $ rmdir empty1
    $ mv readme.txt box
    $ ls box
    readme.txt
    $ rmdir box
    Ошибка: rmdir: box: каталог не пуст
    $ mv missing.txt box
    Ошибка: mv: нет такого файла или каталога: missing.txt
