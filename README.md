# Эмулятор языка оболочки ОС

Учебный проект по дисциплине «Конфигурационное управление»
(ИКБО-41-25, Вариант №22). Практическая работа №1, этапы 1-2.

## 1. Общее описание

Эмулятор командной строки UNIX-подобной ОС с графическим
интерфейсом (GUI). Поддерживает настройку через параметры
командной строки и выполнение стартового скрипта.

## 2. Описание всех функций и настроек

- Окно с заголовком `Эмулятор - [vfs]`, полем вывода и строкой ввода.
- Парсер разбивает ввод на команду и аргументы по пробелам.
- Команды-заглушки: `ls`, `cd` (выводят имя и аргументы), `exit`.
- Неизвестная команда: сообщение об ошибке, работа продолжается.
- Параметры командной строки:
  - `--vfs ПУТЬ` - путь к физическому расположению VFS;
  - `--script ПУТЬ` - путь к стартовому скрипту.
- При запуске в окно выводятся все заданные параметры ([debug]).
- Стартовый скрипт: команды выполняются последовательно, в окне
  видны ввод и вывод. Ошибочные строки пропускаются с сообщением
  об ошибке и номером строки. Если файл скрипта не открывается,
  выводится сообщение об ошибке.

## 3. Описание команд для сборки проекта и запуска тестов

Зависимости не нужны (только стандартная библиотека Python).

    python3 src/main.py [--vfs ПУТЬ] [--script ПУТЬ]

Скрипты для проверки параметров:

    scripts\test_ok.bat        (Windows)
    scripts\test_errors.bat    (Windows)
    bash scripts/test_ok.sh    (Linux/macOS)
    bash scripts/test_errors.sh

## 4. Примеры использования

    python3 src/main.py --vfs vfs --script scripts/startup_ok.txt

В окне появится:

    [debug] Параметры запуска:
    [debug] vfs = vfs
    [debug] script = scripts/startup_ok.txt
    $ ls
    ls
    $ cd projects
    cd projects

Скрипт с ошибками (`scripts/startup_errors.txt`):

    $ foo bar
    Ошибка (строка 2 скрипта): неизвестная команда: foo
